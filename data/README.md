# Data

Written by `cscpi build` (monthly, by GitHub Actions). Nothing here is hand-edited.

| File | Contents |
|---|---|
| `cscpi.csv` | Latest vintage: month, index value (standard deviations from average), number of inputs available, contribution of each input |
| `cscpi.json` | Same series plus a summary (latest value, change, drivers, loadings) for web pages |
| `cscpi.png` | Chart of the latest vintage |
| `audit.csv` | Every input: resolved or not, first and last month, current or stale |
| `releases/cscpi_YYYY-MM.csv` | Every past vintage. The whole history is re-estimated each month, so values revise; old vintages are never overwritten |
| `releases/notes_YYYY-MM.md` | Release notes |
| `releases/linkedin_YYYY-MM.md` | Draft post for the release |
